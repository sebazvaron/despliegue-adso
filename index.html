Control de versiones

Hosting gratuito

GitHub Pages aloja el sitio estático y lo sirve con HTTPS, sin costo.

Dominio personalizado

Un subdominio gratuito de is-a.dev apunta al sitio mediante un registro DNS de tipo CNAME.

Sobre esta práctica

Esta página es el producto de prueba de la evidencia GA10-220501097-AA6-EV01 del programa Análisis y Desarrollo de Software del SENA. El objetivo fue seleccionar una plantilla web gratuita, configurar un hosting y un dominio personalizado gratuitos, y desplegar el sitio para que cualquier persona pueda acceder a él desde una dirección de Internet.
